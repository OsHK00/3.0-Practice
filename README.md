# 3.0 Practice

A small mod for that adds practice tools for practice anyrad3.0

## Features

- Reset the boss at dying (not finished)
- Bind key for resets
- Restart plats
- Option to remove phase-2 portals
- Show your current Carefree Melody proc chance
- increase the speed of the swords

## Requirements

- Any Radiance 3.0
- SFCore

## Build

Set the path to your HK Managed folder in `.env`:

```
HK_PATH=C:\path\to\Hollow Knight_Data\Managed
```
